
# Coplanar Waveguide with Ground V0.1
## Design Parameters
- Substrate Height: 1.27 mm
- Relative Dielectric Constant: 10.2
- Trace Width: 0.3 mm
- Trace Spacing: 0.15 mm
- Metal Thickness: 0.035 mm (35 um)
- Planar Dimensions: 50 mm x 50 mm
## Material Overview
The coplanar waveguide was created using [Rogers Corporation RT/Duroid 6010.2LM](Literature/RT-duroid_6006-6010LM_Laminate_Data_Sheet.pdf).
